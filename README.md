Solmar Bay is an original top-down open-world crime game: explore a sun-soaked coastal city on foot and by car, steal cars, outrun the police as your wanted level rises, and run five story missions for fixer Marisol Vega. Built with plain JavaScript and canvas — no libraries, no network requests.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Move with WASD or arrow keys, E enters or exits a car, Space punches, mouse click fires the pistol, P pauses, M mutes.
